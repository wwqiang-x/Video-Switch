## 项目目标

开发一款面向实际使用的桌面视频格式转换器，支持视频信息展示、缩略图、
FFmpeg 命令行转换、任务进度、取消、错误提示和批量处理。最终代码上传
GitHub，并在 Releases 中提供 Windows 运行包。

## 已确认技术选择

- 使用 Python 3.12+ 和 uv 管理项目。
- 使用 PySide6-Essentials 构建桌面客户端。
- 使用 Qt Widgets、QSS 和 QProcess。
- 使用 ffmpeg/ffprobe 命令行，不接入 FFmpeg API。
- 运行时不调用任何远程 API。
- 使用 pytest、pytest-qt、Ruff 和 PyInstaller。
- 最终打包 Windows 客户端并发布到 GitHub。

## 步骤 3 反馈修复

- 用户发现同一视频以不同文件名导入后出现两条任务。
- 导入服务增加内容指纹，同路径、同内容不同文件名以及同一批重复文件都会去重。
- 用户发现深色主题的“清空任务”确认框按钮文字不可见。
- 为 QMessageBox 及其按钮增加明确的浅色和深色主题样式。
- 确认框按钮改为“清空”和“取消”，默认选择“取消”。
- 增加同内容不同文件名和同大小不同内容的自动化测试。
- 为本地开发测试准备了 FFmpeg 6.0 和 ffprobe 6.0，存放在已忽略的
  `.tools/ffmpeg/bin`，不会提交到 Git。
